# Theme documentation archive

This directory contains historical material moved from the staging wrapper.
It is retained for auditability and recovery, not as a second current source
of truth.

- `jobs/` contains completed and dated implementation plans.
- `visual-reference/` contains design-reference images and rebuild proofs.
- `site-evidence/` contains dated SEO and WordPress inventory records.
- `database-backups/` contains Local database/content backups. The theme
  repository ignores these backup directories and SQL files; they are not
  portable release documentation.

Current operating guidance belongs in the handbook sections above. If an
archived plan conflicts with the current handbook or implementation, the
current code and handbook win.
